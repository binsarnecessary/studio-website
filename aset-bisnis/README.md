# Aset Bisnis — Studio Website

6 dokumen bisnis siap pakai, branding sesuai `docs.md` (hitam #111111, aksen biru #2563EB, Playfair Display + Inter).

| File | Fungsi |
|---|---|
| `quotation.html` | Penawaran harga — kirim setelah konsultasi |
| `invoice.html` | Tagihan DP / pelunasan |
| `contract.html` | Surat Perjanjian Kerja Sama (11 pasal) |
| `proposal.html` | Proposal penawaran lengkap (3 halaman + cover) |
| `company-profile.html` | Profil studio untuk calon client (3 halaman) |
| `pricing.html` | Daftar harga 1 halaman |

## Cara Pakai

1. Buka file di browser (double-click).
2. Edit isi: buka file dengan text editor / VS Code, ganti semua bagian `[dalam kurung siku]` — nama client, nomor dokumen, harga, dll.
3. **Jadikan PDF:** buka di browser → Ctrl+P → "Save as PDF" → margin: None. Layout sudah A4 print-ready.
